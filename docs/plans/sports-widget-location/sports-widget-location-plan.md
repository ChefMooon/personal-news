# Specification & Overview

### 1. Scope & Objective
- **Goal:** Make the Sports dashboard widget show *where* a game is played (city, and country when it is abroad) and make its information easier to read at a glance.
- **In-Scope:**
  - Capture venue city, region and country from the two sports providers (ESPN scoreboard, TheSportsDB), persist them in `sports_events`, and carry them through IPC to the renderer.
  - Render `Venue · City, Region` (or `City, Country` when abroad) in every Sports **widget** surface that currently renders `venue` (list in Phase 2).
  - Make the `showVenue` setting apply at every widget size (Small currently ignores it), rename it in the UI to "Show venue & location", and default it to on for new/reset configs only.
  - Fix the league label that renders a raw ID (for example `Baseball · 4424`).
  - Remove the redundant Win/Loss pill from the Detailed team card.
  - Replace the full-height "No upcoming games scheduled" block in the Detailed team card with a one-line row.
  - When no tracked team plays today, show the soonest upcoming game across tracked teams as a featured "Next up" card in the hero slot of the Small and Medium layouts.
- **Out-of-Scope (decided; do not implement):**
  - The standalone Sports page (`src/renderer/src/routes/Sports.tsx`) and the components used only by it (`TodayGamesStrip.tsx`, `ExpandedGameCard.tsx`). They keep showing `venue` only. Location on the Sports page is a later follow-up.
  - Large size hero behavior. Large keeps today's layout; it gets location through the team cards only. Do not add a featured card to Large.
  - Migrating existing saved widget configs. Saved `showVenue: false` values stay `false`.
  - Repairing existing `sports_leagues` rows whose `name` equals the league ID. Fix the label in the renderer only.
  - Re-fetching or backfilling location for events already cached before the migration. Old rows show venue only until the provider data refreshes them.
  - New dependencies, a new test framework, or changes to `BrowserWindow` security settings or the renderer CSP.
